# Glide Music

Музыкальный плеер экосистемы Glide для **Windows и Linux** — одна программа, одни исходники.

## Возможности

- Библиотека из папки (с подпапками) или отдельных файлов; MP3, FLAC, M4A/AAC, OGG, Opus, WAV.
- Названия и исполнители — **из тегов** (не из имён файлов); без тегов имя «Исполнитель - Название»
  разбирается само. Теги читаются в фоне и кэшируются — большая библиотека не тормозит.
- Обложки — встроенные в файл, иначе находятся по названию (iTunes).
- **Системный плеер** с названием, исполнителем, альбомом и обложкой:
  Windows — плашка «Сейчас играет» и медиаклавиши (SMTC); Linux — MPRIS (медиаклавиши,
  `playerctl`, остров Glide Shell, KDE/GNOME).
- **Мини-плеер поверх всех окон**: обложка, трек, назад / пауза / вперёд. Щелчок или касание по
  ручке — свернуть в полоску, по полоске — развернуть; тянуть — переносить. На Windows —
  глобальная горячая клавиша (по умолчанию Ctrl+Alt+M, меняется в настройках).
- Помнит последний трек и место, громкость, перемешивание и повтор, размер окна.
- Очередь «Играть следующим», честное перемешивание без повторов, «назад» как в других плеерах.
- Discord Rich Presence (выключается в настройках).

## Установка на Linux

```sh
sh install-linux.sh              # собрать и поставить в ~/.local: лаунчер, значок, команда glide-music
sh install-linux.sh --uninstall  # удалить (настройки и библиотека остаются)
```

Собирается папкой (PyInstaller `--onedir`), а не одним файлом: запуск ~0,5 с вместо ~2,5 с — одиночный exe
каждый раз распаковывает себя во временную папку. Прежняя версия остаётся в `~/.local/lib/glide-music.prev`.

## Запуск из исходников

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt        # Windows: .venv\Scripts\pip
.venv/bin/python app.py
```

Сборка exe для Windows — GitHub Actions (`.github/workflows/main.yml`, по тегу `v*`).

## Клавиши

Пробел — пауза (в списке), Enter — играть выбранный, Ctrl+← / Ctrl+→ — трек назад/вперёд,
Ctrl+M — без звука, Ctrl+F — поиск, Ctrl+Shift+M — мини-плеер, Ctrl+, — настройки, Delete — убрать из списка.
